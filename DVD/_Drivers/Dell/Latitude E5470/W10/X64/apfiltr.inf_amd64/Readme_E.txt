 This document describes the installation instructions for Dell Touchpad
 Driver and other important information on how to use the driver.

 Dell Touchpad Driver provides a convenient way to adjust various
 settings of the devices it supports.

 NOTE: You need to log on to the Windows as an administrator-privilege user
       to install the driver.

---------------------------------------------------------------------------
   1. Installing the driver with Installer [interactive mode]
   2. Installing the driver with Installer [silent mode]
   3. Installing the driver with Device Manager
   4. Using the Dell Touchpad Property Sheet
   5. Uninstalling the driver


---------------------------------------------------------------------------
 1. Installing the driver with Installer [interactive mode]
---------------------------------------------------------------------------
 In order to install the driver with Installer in interactive mode, follow
 the instructions below:

 [Windows Vista]
 -------------------------
   1) Run Setup.exe by double-clicking on the file.
   2) Select 'Continue' when prompted.
   3) Press the 'Next' button when the installation wizard is displayed.
   4) Press the 'Finish' button when the driver installation completes.
   5) Press the 'Restart Now' button to restart the computer.

 [Windows XP]
 -------------------------
   1) Run Setup.exe by double-clicking on the file.
   2) Press the 'Next' button when the installation wizard is displayed.
   3) Press the 'Finish' button when the driver installation completes.
   4) Press the 'Yes' button to restart the computer.


---------------------------------------------------------------------------
 2. Installing the driver with Installer [silent mode]
---------------------------------------------------------------------------
 In order to install the driver with Installer in silent mode, use the
 following command:

     Setup.exe /s

   NOTE: You need to run Setup from a privilege-elevated process when you
         are using Windows Vista.


---------------------------------------------------------------------------
 3. Installing the driver with Device Manager
---------------------------------------------------------------------------
 In order to install the driver with Device Manager, follow the
 instructions below:

 [Windows Vista]
 -------------------------
   1) From the Start menu, select 'Control Panel'.
   2) Select 'System and Maintenance'.
   3) Select 'Device Manager'.
   4) Select 'Continue' when prompted.
   5) Select 'PS/2 Compatible Mouse' under 'Mice and other pointing devices'
       category.
   6) From the 'Action' menu, select 'Update Driver Software...'.
   7) Select 'Browse my computer for driver software'.
   8) Select 'Let me pick from a list of device drivers on my computer'.
   9) Press the 'Have Disk...' button.
  10) Press the 'Browse...' button and then specify the .inf file of the
       driver.
  11) Press the 'OK' button when the .inf file is specified.
  12) Press the 'Next' button on the 'Update Driver Software - PS/2
       Compatible Mouse' dialog.
  13) Press the 'Close' button when the driver installation completes.
  14) Press the 'Yes' button to restart the computer.

 [Windows XP]
 -------------------------
   1) From the Start menu, select 'Control Panel'.
   2) Click on 'Performance and Maintenance'.
   3) Click on 'System'.
   4) Click on the 'Hardware' tab.
   5) Press the 'Device Manager' button.
   6) Select 'PS/2 Compatible Mouse' under 'Mice and other pointing devices'
       category.
   7) From the 'Action' menu, select 'Update Driver...'.
   8) Select 'No, not this time' and then press the 'Next' button.
   9) Select 'Install from a list of specific location (Advanced)' and then
       press the 'Next' button.
  10) Select 'Don't search. I will choose the driver to install.' and then
       press the 'Next' button.
  11) Press the 'Have Disk...' button.
  12) Press the 'Browse...' button and then specify the .inf file of the
       driver.
  13) Press the 'OK' button when the .inf file is specified.
  14) Press the 'Next' button
  15) Press the 'Finish' button when the driver installation completes.
  16) Press the 'Yes' button to restart the computer.


---------------------------------------------------------------------------
 4. Using the Dell Touchpad Property Sheet
---------------------------------------------------------------------------
 In order to use the Dell Touchpad Property Sheet, open 'Mouse Properties' by
 following the instructions below and then click on the 'Dell Touchpad' tab.

 [Windows Vista]
 -------------------------
   1) From the Start menu, select 'Control Panel'.
   2) Click on 'Mouse' in the 'Hardware and Sound' group to open the
       'Mouse Properties' dialog.

 [Windows XP]
 -------------------------
   1) From the Start menu, select 'Control Panel'.
   2) Click on 'Printers and Other Hardware'.
   3) Click on 'Mouse' to open 'Mouse Properties' dialog.


---------------------------------------------------------------------------
 5. Uninstalling the driver
---------------------------------------------------------------------------
 In order to uninstall the driver, follow the instructions below:

 [Windows Vista]
 -------------------------
   1) From the Start menu, select 'Control Panel'.
   2) Click on 'Uninstall a program' in the 'Programs' category.
   3) Select 'Dell Touchpad'.
   4) Press the 'Uninstall/Change' button.
   5) Press the 'Continue' button when prompted.
   6) Press the 'OK' button when 'Uninstaller' dialog is displayed.
   7) Press the 'Close' button when the driver uninstallation completes.

 [Windows XP]
 -------------------------
   1) From the Start menu, select 'Control Panel'.
   2) Click on 'Add or Remove Programs'.
   3) Select 'Dell Touchpad'.
   4) Press the 'Change/Remove' button.
   5) Press the 'OK' button when 'Uninstaller' dialog is displayed.
   6) Press the 'Close' button when the driver uninstallation completes.
