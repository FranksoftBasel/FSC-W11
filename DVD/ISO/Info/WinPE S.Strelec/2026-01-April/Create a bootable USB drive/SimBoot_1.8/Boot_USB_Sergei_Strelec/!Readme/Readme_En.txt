The easiest and recommended way:

1. Open an image "Boot_CD_USB_Sergei_Strelec_2015_v7.X-8.X.iso" in UltraIso.
2. Copy the entire contents of the image to the root directory of the USB drive (see "ready_to_boot.png").
3. Make sure what file "/SSTR/bootmgr" exists on the USB drive, if not - copy file "bootmgr" from "root" of the image.

Done.
